# Node.js and npm publishing ecosystem, September 2026

Research for modernizing get-title-at-url (ESM, last published 2022-11; axios, meow 11, ava 5, xo 0.53, nyc, Travis, Snyk, Coveralls). All versions and dates were verified on 2026-09-24 against the sources named; nothing below is from memory. UNVERIFIED marks what could not be confirmed.

## Summary

- Node: 20 reached end of life 2026-04-30; 22 is Maintenance LTS until 2027-04-30; 24 is Active LTS (maintenance from 2026-10-20, end of life 2028-04-30); 26 is Current and becomes Active LTS 2026-10-28.
- npm: trusted publishing (OIDC) GA since 2025-07-31; since 2026-09-03 a trusted-publisher config defaults to staged publishing (`npm stage publish`, npm 11.15+, approval with 2FA on npmjs.com); no token and no provenance flag needed; classic tokens revoked 2025-12-09, granular tokens live at most 90 days; npm 12 is `latest` and blocks dependency install scripts by default.
- GitHub Actions: checkout v7.0.1, setup-node v7.0.0, upload-artifact v7.0.1; the Node 20 action runtime was removed 2026-09-23; `ubuntu-latest` moves to 26.04 between 2026-10-19 and 2026-11-19; pin actions to SHAs, Dependabot updates the pins.
- Tools: xo 5.0.1 (flat config, Node 22+), ava 8.0.1 (Node 22.20+), meow 14.1.0 (Node 20+, zero deps), c8 12.0.0, `node:test` stable since 20 but its coverage is still experimental; `fetch` stable since 21, `URL.canParse` since 18.17 and 19.9, `AbortSignal.any` since 20.3.
- Package hygiene: `exports` with `types` first and a `./package.json` subpath, `sideEffects: false`, commit the lockfile, skip `packageManager`, Dependabot cooldown (3 days by default), drop Snyk, no coverage service needed.

## 2. npm publishing from GitHub Actions

- Trusted publishing (OIDC) is GA since 2025-07-31. (https://github.blog/changelog/2025-07-31-npm-trusted-publishing-with-oidc-is-generally-available/)
- Configure on an existing package: npmjs.com -> package -> Settings -> Trusted publishing. GitHub Actions fields: Organization or user (required), Repository (required), Workflow filename (filename only with .yml/.yaml, not a path; required), Environment name (optional), Allowed actions (`npm stage publish` and/or `npm publish`). Limits: max 10 publishers per package, existing entries cannot be edited (delete and recreate), self-hosted runners unsupported. (https://docs.npmjs.com/trusted-publishers, last edited 2026-09-03)
- Multiple configurations per package since 2026-09-03; direct `npm publish` is opt-in per configuration, staging is on by default, and GitHub "recommend[s] keeping your configurations to staging only". (https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/)
- Workflow needs `permissions: id-token set to write`; npm CLI >= 11.5.1 and Node >= 22.14.0 on the runner; no `--provenance` flag (provenance is automatic for public packages from public repos on GitHub Actions); no NPM_TOKEN for the publish step (a read token only if private deps are installed). `repository.url` in package.json "must exactly match your GitHub repository". (docs.npmjs.com/trusted-publishers, 2026-09-03; https://docs.npmjs.com/generating-provenance-statements, 2026-05-04: repository must match, case-sensitive)
- package.json: `publishConfig.provenance: true` is only the non-OIDC route (npm >= 9.5.0); not needed with trusted publishing. `publishConfig.access` is irrelevant for an unscoped package ("Unscoped packages cannot be set to restricted"). npm 12.1.0: a `provenance-file` takes precedence over OIDC provenance. (https://docs.npmjs.com/cli/v11/commands/npm-publish; https://github.com/npm/cli/releases/tag/v12.1.0, 2026-09-22)
- Staged publishing GA 2026-05-22 (npm >= 11.15.0): `npm stage publish` puts the tarball in a queue; a maintainer approves with 2FA after malware scanning. npm 12.1.0 (2026-09-22) adds read-write-stage-only granular tokens. (https://github.blog/changelog/2026-05-22-staged-publishing-and-new-install-time-controls-for-npm/; https://docs.npmjs.com/staged-publishing/)
- Tokens: classic tokens permanently revoked 2025-12-09 (creation disabled 2025-11-05); granular write tokens default 7 days, max 90 days; new write tokens enforce 2FA by default with "Bypass 2FA" unchecked by default; `npm login` now yields a 2-hour session with 2FA enforced for publishing; new TOTP 2FA setups disabled from October 2025 in favour of WebAuthn/passkeys. Bypass-2FA tokens lost sensitive operations (token, package-access, trusted-publishing changes) on 2026-07-31 and are targeted to lose direct publishing in January 2027 (read + stage only). (https://github.blog/changelog/2025-09-29-strengthening-npm-security-important-changes-to-authentication-and-token-management/; .../2025-11-05-npm-security-update-classic-token-creation-disabled-and-granular-token-changes/; .../2025-12-09-npm-classic-tokens-revoked-session-based-auth-and-cli-token-management-now-available/; .../2026-07-08-npm-install-time-security-and-gat-bypass2fa-deprecation/; .../2026-07-31-restricting-npm-bypass-2fa-granular-access-tokens/)
- After adding the trusted publisher, the docs recommend the package setting "Require two-factor authentication and disallow tokens". (docs.npmjs.com/trusted-publishers)
- npm 12 is `latest` (12.0.0 on 2026-07-08, 12.1.0 on 2026-09-22): supports Node ^22.22.2 || ^24.15.0 || >=26; dependency lifecycle scripts are blocked unless allowed by the root package's `allowScripts`; `allow-git` and `allow-remote` default to "none". (https://github.com/npm/cli/releases/tag/v12.0.0; https://registry.npmjs.org/npm dist-tags, 2026-09-24)

## 6. Small ESM-only package checklist (2025-2026)

- `exports`: `{".": {"types": "./index.d.ts", "default": "./index.js"}, "./package.json": "./package.json"}`; Node: the `types` condition "should always be included first", conditions go most to least specific, and `exports` encapsulates all other subpaths. TypeScript matches `types` and `default`. (https://nodejs.org/api/packages.html; https://www.typescriptlang.org/docs/handbook/modules/reference.html)
- Types for a JS package: hand-written `index.d.ts` checked by tsd (sindresorhus style), or JSDoc plus `tsc` with `allowJs`, `declaration`, `emitDeclarationOnly`. Verify with `npx attw (the arethetypeswrong CLI) --pack . --profile esm-only` (0.18.5, 2026-07-09) and `npx publint` (0.3.24, 2026-08-19). (https://www.typescriptlang.org/docs/handbook/declaration-files/dts-from-js.html; https://github.com/arethetypeswrong/arethetypeswrong.github.io; https://publint.dev/docs/)
- `engines` is advisory unless `engine-strict`; `files` allowlist (package.json, README, LICENSE, main and bin always included); `funding` is an object with a URL; `sideEffects: false` only for pure modules (fine for this package); `packageManager` only matters with Corepack, which Node 25+ no longer ships ("build: stop distributing Corepack"), so skip it. (https://docs.npmjs.com/cli/v12/configuring-npm/package-json; https://webpack.js.org/guides/tree-shaking/; https://nodejs.org/en/blog/release/v25.0.0, 2025-10-15)
- package-lock.json is "intended to be committed into source repositories" and is never published; commit it. `npm pkg fix` "auto corrects common errors in your package.json". (https://docs.npmjs.com/cli/v11/configuring-npm/package-lock-json; https://docs.npmjs.com/cli/v11/commands/npm-pkg)
- Supply chain: Shai-Hulud (September 2025) and its 2025-11-24 second wave spread through install scripts; put `ignore-scripts=true` in the project `.npmrc` (npm 12 already blocks dependency scripts by default via `allowScripts`; `ignore-scripts` still defaults to false; `min-release-age` exists). Dependabot `cooldown` GA 2025-07-01 and a 3-day default since 2026-07-14 (`cooldown: default-days`, `semver-major-days`...), `groups` with `patterns`/`update-types`, for both `npm` and `github-actions` ecosystems. OpenSSF Scorecard: ossf/scorecard-action v2.4.4 (2026-07-23). (https://snyk.io/articles/npm-security-best-practices-shai-hulud-attack/; https://docs.npmjs.com/cli/v12/using-npm/config/; https://github.blog/changelog/2025-07-01-dependabot-supports-configuration-of-a-minimum-package-age/; https://github.blog/changelog/2026-07-14-dependabot-version-updates-introduce-default-package-cooldown/; https://docs.github.com/en/code-security/reference/supply-chain-security/dependabot-options-reference)
- Snyk free plan today: 100 Snyk Code tests/month, 5 projects, plus an open-source maintainer programme; the "200 Open Source tests/month" figure is UNVERIFIED (secondary sources only). For a hobby package the usual choice is Dependabot (security + version PRs, free) plus `npm audit`; drop the `.snyk` file unless Snyk is wanted. (https://snyk.io/plans/, fetched 2026-09-24)
- Coverage services: Coveralls is alive (coverallsapp/github-action v2.3.8, 2026-07-27; incidents Feb 2026 on status.coveralls.io); Codecov is free for open source (codecov/codecov-action v7.1.1, 2026-09-17; ava itself uploads to Codecov). Simplest for a tiny package: built-in coverage table plus thresholds in the CI log, no service. (GitHub releases API; https://about.codecov.io/for/open-source/)
