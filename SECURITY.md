# Security policy

## Reporting a problem

Open an issue or a pull request, or start a thread in [Discussions](https://github.com/m4bwav/get-title-at-url/discussions) and I'll take a look. You can also report privately: open the repository's **Security** tab and choose **Report a vulnerability**.

A confirmed problem is fixed in a new release, and the advisory is published once the fix is on npm.

## Supported versions

Only the latest major version (3.x) gets security fixes.
